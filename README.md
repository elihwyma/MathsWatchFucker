# MathsWatchFucker

## How it works
The program abuses the fact that a large number of users are still using the default password. This script will loop through every username and take their answers for a set task. It will then output the answers of the student with the highest mark.

## How to use it 
- Inside `main.swift` add your array of usernames, add the default password, and set the ID of the task from MathsWatch (the last part of the URL).
- Next either press `Run` in Xcode, or `swift run` if you're in the command line.
